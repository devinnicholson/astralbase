# Support

Use a GitHub issue for usage questions, reproducible defects, documentation
errors, or narrowly scoped feature requests. Security reports follow
[SECURITY.md](SECURITY.md).

Please include the Astralbase commit or version, Rust version, enabled features,
platform, exact command, and a minimal FEN or artifact when applicable.

The supported v0.1 surface is the bounded in-memory retrograde engine. The
`partizan-dataset` feature is research tooling with versioned file schemas and an
otherwise unstable Rust API. Draw solving, exhaustive tablebases, unbounded
position generation, and chess advice are outside the support boundary.
